# نسخه جدید ربات حضور و غیاب و مدیریت کادر (نسخه چندپروژه‌ای)

این نسخه طبق سند جامع نیازمندی و معماری بازنویسی شده و ساختار تک‌پروژه‌ای و سراسری قبلی را به یک سیستم یکپارچه چندپروژه‌ای (Multi-Project) ارتقا داده است.

## ماژول‌های سیستم:
1. `config.py`: مدیریت متغیرهای محیطی و مسیرها
2. `utils.py`: محاسبات تأخیر، نرمال‌سازی فارسی و ایموجی‌ها
3. `db_manager.py`: اتصال امن به SQLite، همگام‌سازی اختیاری با MySQL و بکاپ
4. `permission_manager.py`: کنترل دسترسی پروژه‌محور و فیلتر جنسیت
5. `project_manager.py`: مدیریت چرخه عمر پروژه‌ها و چارت سازمانی
6. `staff_manager.py`: مدیریت کادر، جستجو و گروه‌بندی نیروها
7. `attendance_manager.py`: مدیریت برنامه کلاس‌ها (Schedules)، جلسات (Sessions) و حضور/کارت
8. `shortage_manager.py`: فرآیند ثبت و تأمین کمبود نیرو
9. `excel_manager.py`: ورود، خروج و تطبیق با قالب رسمی اکسل
10. `report_manager.py`: داشبورد آماری زنده و لاگ عملکرد
11. `worker_manager.py`: ورکر‌های پس‌زمینه (گزارش ۲۳:۳۰، یادآوری تأخیر، برودکست و بکاپ)
12. `bot.py`: واسط تعاملی ربات در پیام‌رسان بله

## نحوه اجرا:
```bash
pip install -r requirements.txt
cp .env.example .env
# ویرایش توکن و تنظیمات در فایل .env
python bot.py
```
